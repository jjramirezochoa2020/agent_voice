# SPEC-0002 — Integrar el widget oficial de ElevenLabs

## 1. Objetivo

Conectar la landing page de Empire Lead Company (SPEC-0001) con el agente real ya creado en
ElevenLabs, usando el **widget oficial embebible** que entrega el proveedor.

## 2. Código entregado por ElevenLabs

```html
<elevenlabs-convai agent-id="agent_9101m5mtb0t0erb9rc22a6fpw2fn"></elevenlabs-convai>
<script src="https://unpkg.com/@elevenlabs/convai-widget-embed" async type="text/javascript"></script>
```

| Dato | Valor |
|---|---|
| Agent ID | `agent_9101m5mtb0t0erb9rc22a6fpw2fn` |
| Script | `@elevenlabs/convai-widget-embed` servido desde unpkg |
| Elemento | `<elevenlabs-convai>` (web component) |

El Agent ID es público por diseño: viaja en el HTML de cualquier página que embeba el agente.
La protección se hace en la consola de ElevenLabs con la lista de dominios permitidos.

## 3. Alcance

### Incluye
- Añadir el widget oficial a la página.
- Configurar el Agent ID por variable de entorno, no escrito a mano en el HTML.
- Fijar la versión del script de unpkg.
- Adaptar los botones "Hablar con el asistente" (header, hero y sección del agente) al nuevo widget.
- Actualizar la documentación de SPEC-0001 que cambia con esta decisión.

### No incluye
- Cambios en el prompt, la voz o la base de conocimiento del agente en ElevenLabs.
- Cambios en las demás secciones de la página.

## 4. Cambio respecto a SPEC-0001

SPEC-0001 decidió una **UI de widget propia** sobre el SDK `@elevenlabs/client` (decisiones D3 y
D4 de `spec0001/architecture.md`). Esta spec la **sustituye por el widget oficial**:

| Aspecto | SPEC-0001 (actual) | SPEC-0002 (nuevo) |
|---|---|---|
| UI de la conversación | Propia (`VoiceWidget.ts`) | La del widget de ElevenLabs |
| Integración | SDK `@elevenlabs/client` | `<elevenlabs-convai>` + script embed |
| Estados, transcripción, permiso de micrófono | Implementados por nosotros | Los gestiona el widget |
| Estilo | Tokens propios | Configurable desde la consola de ElevenLabs |
| Cambio de proveedor | Un archivo (`VoiceProvider`) | Sustituir el embed |

**Consecuencias a aceptar:**
- Se pierde el control visual fino del widget (F10–F12 de SPEC-0001 pasan a depender del proveedor).
- Se elimina el SDK `@elevenlabs/client` y el código de `src/voice/` que deje de usarse.

## 5. Requisitos

| # | Descripción |
|---|---|
| R1 | La página carga el widget oficial con el Agent ID de la sección 2. |
| R2 | El Agent ID se lee de `VITE_ELEVENLABS_AGENT_ID`; `.env.example` lo documenta. |
| R3 | El script se carga desde unpkg con **versión exacta** (`@elevenlabs/convai-widget-embed@x.y.z`), no la última sin fijar. |
| R4 | El script se carga de forma asíncrona y no bloquea el render de la página. |
| R5 | Si no hay Agent ID configurado, el widget no se inserta y la sección del agente muestra "Asistente no disponible" con correo y teléfono (se mantiene AC10 de SPEC-0001). |
| R6 | El widget se muestra en idioma español. |
| R7 | Los botones "Hablar con el asistente" del header, el hero y la sección del agente llevan al visitante al widget (ver pregunta abierta P1). |
| R8 | La sección "Habla con nuestro asistente" conserva el texto y los ejemplos de preguntas. |
| R9 | El widget no tapa contenido importante en móvil (360 px), en particular el footer y el aviso de datos ficticios. |
| R10 | Se eliminan las dependencias y el código del widget propio que queden sin uso. |

## 6. Criterios de aceptación

- [ ] Con el Agent ID configurado, el widget de ElevenLabs aparece y permite conversar con el agente.
- [ ] El Agent ID no está escrito a mano en `index.html` ni en el código fuente; sale de `.env`.
- [ ] La URL del script incluye una versión exacta.
- [ ] Sin `.env`, la página carga sin errores en consola y muestra "Asistente no disponible".
- [ ] Los tres botones "Hablar con el asistente" llevan al widget.
- [ ] En móvil el widget no oculta el aviso de datos ficticios del footer.
- [ ] `npm run build` termina sin errores y sin dependencias sin uso.
- [ ] El guion `agent/test-script.md` (T0–T10) se ejecuta con el agente real y se registran los resultados.
- [ ] `spec0001/architecture.md` y `spec0001/epics.md` reflejan el cambio de D3/D4.
